A kind, funny fortune for a houseplant on the windowsill:

> "A sunny week is coming: you'll grow a leaf so bold, even the cat will ask permission before sitting near you."

`main.ts` (Node 22, stdlib only, no network) writes this fortune to `/output/entry.txt` deterministically — the same single line on every run.
